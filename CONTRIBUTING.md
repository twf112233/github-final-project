# Contributing to Simple Interest Calculator

First off, thank you for taking the time to contribute! 🎉

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue detailing:
* A quick description of the bug.
* Steps to reproduce it.
* Expected vs. actual behavior.

### Suggesting Enhancements & Ideas
Have an idea to make this tool better? Feel free to open an issue or submit a pull request with your suggestions for enhancements, new features, or ideas.

### Code and Documentation Improvements
* **Bug Fixes**: Check open issues for bugs you can resolve.
* **Documentation**: Clear documentation helps everyone. Improvements to the README or code comments are always appreciated.

---
Thank you once again for supporting this project!
