# Simple Interest Calculator

A simple command-line application (or web tool) built to calculate simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest is calculated using the formula:
$$\text{Simple Interest} = \frac{P \times T \times R}{100}$$

Where:
* **P** = Principal amount (the initial amount of money)
* **T** = Time period (in years)
* **R** = Annual interest rate (percentage)

---

## Features
* Calculates simple interest accurately.
* Easy-to-use interface or command line inputs.
* Lightweight and fast.

---

## How to Use
1. Clone or download this repository.
2. Open the project files in your preferred code editor or terminal.
3. Run the script/program to input the Principal, Time, and Rate.
4. View the calculated interest and total amount.
